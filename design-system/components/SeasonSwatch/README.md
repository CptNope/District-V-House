# SeasonSwatch

The "Restyle the window" control: four toggle buttons (Holiday, Winter, Garden, Harvest), each with a three-chip strip (glass, leaf, ornament of that season), the season name and its months. `aria-pressed` marks the current one. Clicking dims the window panes, swaps the season theme and photos, and brings the lights back up.

Sits on the `ornament` band in `on-ornament` color. Two columns on phones.
