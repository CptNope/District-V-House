# Button

Three painted buttons: **gilt** (primary, `leaf` fill, `sash` text, `shadow-button`), **line** (secondary on glass, 1.5px `leaf` border, `frost` text) and **dark** (on the gold Visit band, `sash` fill, `leaf` text). Radius `radius-md`, 15×22px padding, `button` text style, an 18px line icon on the left.

One gilt button per region. The verb names the action ("Get directions", "Start a design project"). Phone numbers are buttons too: a `tel:` link showing the number. The consumer provides the href and icon.
