# GiltLettering

Sign-painted gold leaf: Gloock in `leaf`, a 1px lighter keyline on top, and a `gilt-shade` drop shade in the season's `shade`. For the arched name in the transom (an SVG textPath on a shallow quadratic arc, a shade copy offset 3,4 underneath), headings on glass, pane captions and the Stroll title.

Only on `glass`, `glass-2` or photo panes under the glass scrim. Never on frost or gold. Never gradient-filled.
