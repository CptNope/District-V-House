# PriceTag

A string tag, like the ones on a vendor's booth, for the categories and vendor names in the Collective section. `leaf` tinted 30% into `frost`, `sash` text, a hole punched at the left, a notched left edge. Tags in a row tilt a degree or two at irregular intervals, the way real tags hang.

Use on `frost` ground only. Words, not sentences. Never use it as a button.
